# myTimeSeries

myTimeSeries is a package that holds the SQLite tables of several time series such as the quote secors change in percent over time.

# Installation

Install the package easily via `pip`:

pip install mytimeseries

## Project Structure

Since this package contains multiple files, here is a quick overview of how the modules interact:

myTimeSeries/   
├── __init__.py.    
├── mySectorsTimeSeries.py.                        
├── mySectorsTimeSeriesDefinitions.py.     
├── myTableSQLSectorsTimeSeries.py.
